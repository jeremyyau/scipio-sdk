# LaTeX Whitepaper Template for Project SCIPIO

This directory contains the LaTeX source files and build configurations for the SCIPIO Whitepaper.

## Author Information
- **Primary Author**: Jeremy Yau
- **Subject**: Time-Based Isomorphic DOM Obfuscation (SCIPIO Protocol)

## How to Compile
You can compile this paper locally using `pdflatex` or by uploading this directory to [Overleaf](https://www.overleaf.com) as a ZIP file.
